## 0. 检索口径与排除规则

| 项 | 说明 |
| --- | --- |
| 欢迎度 | 优先 `stargazers_count`；兼顾奖项/基金会背书（如 Antura、GCompris）与近期活跃 |
| 纳入 | 明确面向儿童启蒙/学校教育互动；README 能提炼可复用玩法机制 |
| 集成硬过滤 | 功能必须能 **不联网、浏览器内演示**（Web Speech / localStorage 可接受） |
| 排除假阳性 | Minecraft 模组、成人工具带 “kids” 字样、学校 MIS、大学 CS 书单等 |
| 本阶段不做 | 不克隆第三方代码进业务、不改 Vue 实现 |

**检索关键词（节选）**：`kids game` / `preschool` / `literacy kids` / `kids math` / `memory game kids` / `GCompris` / `phonics` / 中文「儿童 启蒙」等。

## 2. 适合本项目的功能清单（文档 B）

说明：下列功能均可在 **纯前端、不联网** 条件下演示（语音用浏览器 Web Speech；进度用 localStorage）。优先级：

- **P0**：教育帮助大 + 与现有岛契合 + 实现成本可控  
- **P1**：价值高，适合下一岛或现有岛加深  
- **P2**：有价值但年龄/范围略偏，或实现量较大  

### 2.1 P0（建议优先）

| ID | 功能名 | 教育价值 | 交互 | 建议挂载 | 离线实现要点 | 灵感来源 |
| --- | --- | --- | --- | --- | --- | --- |
| F01 | 记忆翻牌·数量/数字 | 工作记忆 + 形义对应（柱 A/B） | 翻两张配对（「5」↔ 五只苹果） | 认一认新关或小游戏岛 | 4×3～6×4 网格；错配轻晃；对配 Celebrate | memory-game |
| F02 | 记忆翻牌·颜色/图形 | 属性辨识 + 记忆 | 同色或同形配对 | 颜色图形线扩展 | 复用 ATTR 词表；认图形用中性色防干扰 | memory-game、kids-games |
| F03 | 找不同 / What changed | 观察力、注意 | 两屏对比点差异 | 认一认扩展 / 新岛「小侦探」 | 改动 1～3 处数量或颜色；点对高亮 | memory-game 小游戏 |

| F06 | 家长角（长按解锁） | 防沉迷、可重置、隐私说明 | 长按 2s 进设置 | 全局 SenseChrome | 本地时长统计、重置进度、无联网 | memory-game、kids-games、博物馆 |

| F09 | 干扰项易混优先 | 抗易混（红橙、圆椭圆等） | 看图点名已有，强化出题 | 颜色图形 / 认数字 | 已有 confusable 策略固化为通用出题器 | 本项目 + GCompris 活动设计 |
